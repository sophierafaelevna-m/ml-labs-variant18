# Комплект сдачи ЛР1 и ЛР2

## Обязательные материалы

- [ ] ZIP-архив репозитория из финальной main.
- [ ] Ссылка на GitHub-репозиторий.
- [ ] Человекочитаемый отчёт ЛР1.
- [ ] Человекочитаемый отчёт ЛР2.
- [ ] Скринкаст 3–5 минут.
- [ ] Рецензия ИИ по приложению А.
- [ ] Критический комментарий к каждому пункту рецензии.
- [ ] defense_checklist.md с раскрытием использования ИИ.

## Контроль качества

- [ ] В отчётах указаны правильные хеши коммитов и данных.
- [ ] Метрики согласованы между CSV, JSON и отчётом.
- [ ] Сохранённые модели загружаются.
- [ ] Негативные проверки имеют подтверждающие логи.
- [ ] В GitHub проверки CI завершились успешно.
- [ ] Pull Request в main закрыт с успешным слиянием.

## Файлы, которые предстоит подготовить

- `submission/ai_review.md` — фактическая рецензия.
- `submission/review_comment.md` — аргументированный ответ на рецензию.
- `submission/screencast.mp4` — запись защиты, если файл хранится в комплекте.

Не отмечать пункты выполненными до фактической проверки.
