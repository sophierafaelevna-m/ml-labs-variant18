# Использование ИИ и критический анализ — ЛР5

## Как использовался ИИ

При выполнении лабораторной работы ChatGPT применялся как
вспомогательный инструмент для проектирования структуры генератора,
подготовки Python-кода, разработки тестов, анализа ошибок
и оформления результатов экспериментов.

Результаты работы ИИ проверялись запуском программ,
автоматизированными тестами и анализом полученных метрик.

## Критический анализ предложенного решения

### 1. Ограничение режима similar

Режим similar использует повторную выборку текстов из исходного
обучающего набора. Это помогает сохранять статистические
характеристики, но не гарантирует создания принципиально новых текстов.

Вывод: полученные данные подходят для проверки статистического
сходства, но не должны рассматриваться как полностью новые
независимые тексты.

### 2. Ограничение режима random

Случайная генерация слов создаёт заметные отличия в статистических
характеристиках, но не обеспечивает связность и смысловую
корректность текста.

Вывод: этот режим подходит для моделирования сильного
распределительного сдвига, но не для создания реалистичных документов.

### 3. Ограничения PSI и KS

PSI зависит от способа разбиения значений на интервалы.
KS позволяет сравнивать распределения числовых характеристик,
но не оценивает семантическое качество текстов.

Вывод: метрики необходимо интерпретировать совместно,
с учётом особенностей генерации.

### 4. Распределение классов

В режиме random распределение классов может оставаться близким
к исходному, даже когда характеристики текстов существенно отличаются.

Вывод: отличие синтетических данных не обязательно проявляется
одновременно во всех характеристиках.

### 5. Проверка воспроизводимости

Совпадение SHA256 при повторной генерации подтверждает
детерминированность результата в проверенном окружении.

Дополнительно выполнен отрицательный контроль:
после намеренного нарушения работы с seed тест обнаружил ошибку.

Вывод: проверка подтверждает воспроизводимость в рамках
проведённого эксперимента, но не гарантирует побайтового
совпадения между всеми версиями библиотек и платформами.

## Самостоятельная проверка результатов

Выполнено 27 автоматизированных тестов.
Все тесты завершились успешно.

Покрытие кода составило 88%.

Для режима similar критерии выполнены по 8 из 8 характеристик.
Для режима random критерии выполнены по 7 из 8 характеристик.

Таким образом, предложения ИИ не принимались без проверки:
их корректность оценивалась по тестам, метрикам,
воспроизводимости и ограничениям выбранного подхода.
